# Buddha reconstruction study

Based on Main at `9d6b1a9` (PR #65, 21 October 2026), after reviewing Claude's destination-model changes in PRs #61–65 and the user's five statue screenshots. No original mesh was available. This is a newly constructed mesh, not a recovered scan.

## What is available

- `sculpture-preview.html`: larger desktop review layout, face/hand/foot/arm detail, rotate, zoom, select front/side/rear/above, switch neutral clay and game colours, compare three gestures, and inspect four complete game locations.
- `buddha-teach.glb`, `buddha-lap.glb`, `buddha-earth.glb`: self-contained neutral-stone glTF 2.0 models, approximately 6.2–6.3 MB each. These contain actual geometry, without image billboards or external textures.
- `seated-sculpture.js`: the face, eyelid surfaces, ears, spiral curls, hands, feet, crossed-leg cloth and elliptical lotus seat.
- `sculpture-anatomy-data.js`: continuous palms, thumb pads, bent fingers, wrists, heels, insteps and toes, generated by `scripts/build-sculpture-anatomy.mjs`. Detailed study meshes include small nail plates. Game meshes use fewer samples.
- `sculpture-robe-data.js`: indexed, quantized meshes generated offline by `scripts/build-sculpture-robe.mjs`. Smooth unions connect the torso, shoulders and sleeves; a flared lower robe reaches the seat. Detailed review meshes and lighter game meshes are generated separately. Saved field-gradient normals soften the reconstructed surface.

The local game integration replaces the seated Buddha in squares 77, 93, 100 and 101. The last two also use the new lotus seat. Standing Buddhas, monks, crowned figures, wrathful figures and other humans retain Main's previous construction. Each destination still merges into at most four material meshes.

## Visual status

This is an ongoing reconstruction for visual review. The references remain the quality target. The revised model separates the overlapping crossed legs, lifts the rear foot above the cloth, adds exposed wrists, shapes closed eyelids and lips, fills the curl pattern, rounds the crown, lengthens the lotus petals and carries the back drape down to the seat. The latest hand/foot pass replaces capped palms and bar-shaped feet with continuous anatomy, corrects teaching fingertip contact, stacks the meditation hands, turns the soles upward in the lotus posture, and places the earth-touching hand in front of the knee. The arm pass preserves the approved hand meshes and anchors, tapers the forearms into recessed cuff openings, adds rolled cloth edges, shapes the elbow bends, and replaces cylindrical hanging sleeves with broader drapes and gathered folds. The shoulder drape connects continuously to the torso. Detailed robe sampling is higher than the game version. The face and cloth still lack the reference sculpture's naturalism; the overall reconstruction remains a visual study. It should not be described as an exact replica or a completed replacement for all human figures.

## Reproduce

Use Node with the repository's development dependencies (`three`, and `jsdom` for the scene harness):

```sh
node scripts/build-sculpture-robe.mjs
node scripts/build-sculpture-anatomy.mjs
node scripts/export-buddha-models.mjs
node scripts/build-sw.cjs
node tests/sculpture-anatomy.mjs
node tests/square-models.mjs
node tests/offline.mjs
```

Serve the preview from a separate localhost origin from the game. The game's existing service worker treats navigation requests as application-shell navigation, so opening the review page under an already controlled origin can show the game instead. Run `python3 scripts/serve-sculpture-preview.py --port 4187` and open `http://localhost:4187/`. The dedicated server serves the review at `/` and sends `Cache-Control: no-store` so regenerated mesh modules do not remain stale in the browser.

The integration is prepared on `codex/reference-buddha-sculpture` for review against `main`. Merging and production deployment are separate from this reconstruction.
