# Future destination iconography

Place approved destination images here, conventionally `001.webp` through `104.webp`, then register each image, accessible description, credit, and display dimensions in `rebirth-iconography.js`.

The manifest connects the image to both the 3D game waypoint and the destination reading card. Images are loaded only when Rebirth is entered. Keep attribution and any permission information with the asset. The game retains its existing geometry and text if an image is absent or fails to load.

No historical artwork is bundled in this directory yet. See [the integration notes](../../docs/rebirth.md) for an example.
